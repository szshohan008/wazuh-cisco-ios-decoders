# wazuh-cisco-ios-decoders
Production-ready Cisco IOS custom decoders for Wazuh.

These decoders normalize Cisco IOS syslog events into structured Wazuh fields, making them suitable for dashboards, detection rules, and SOC investigations.

Features

ACL Traffic Parsing

Login Success Detection

Login Failure Detection

INVALID_FRAG_LENGTH Detection

Source/Destination IP extraction

Port extraction

PCRE2 optimized regex
